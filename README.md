# Shark Atlas

A self-contained, responsive static website.

## Run locally
Open `index.html` in a browser, or use any simple local server.

## Deploy
Upload the contents of this folder to Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.

## Notes
- No build step or framework is required.
- All interactions are local JavaScript.
- External source links are provided on `sources.html`.
- Facts such as species counts, maximum sizes, and fossil dates are intentionally approximate where the scientific literature is variable.
